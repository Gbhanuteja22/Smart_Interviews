Uncertain Steps
Given N steps, calculate number of possible ways to reach the 0th step from the Nth step.
From a given step you can go down 3 ways:Jump 1 step at a time.Jump 2 steps at a time.Jump 3 steps at a time.Note: We can jump 3 steps at most once during the entire process.

Input Format
First line of input contains T - number of test cases. Its followed by T lines, each line contains N - denoting the number of steps.

Output Format
For each test case, print number of ways we can reach the 0th step, separated by newline. Since the answer can be very large, print answer % 109+7.

Constraints
30 points
1 <= T <= 100
1 <= N <= 105

70 points
1 <= T <= 105
1 <= N <= 106

Example
Input
2
4
2

Output
7
2

Explanation

Test Case 1:
Here's the list of possible ways to reach 0th step from 4th:
1 1 1 1
1 1 2
1 2 1
1 3
2 1 1
2 2
3 1
