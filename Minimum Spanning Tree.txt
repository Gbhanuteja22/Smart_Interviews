Minimum Spanning Tree
You are given a weighted, undirected, connected, simple graph with N vertices and M edges. Your task is to convert the graph to Minimum Spanning Tree.

Input Format
The first line contains an integer T, representing the number of test cases. The first line of each test case contains N - number of vertices and M - number of edges in the graph. The next M lines each contain three integers (u,v,w) representing an undirected edge between vertices u and v with weight w.

Output Format
For each test case, output the sum of weights of edges in the Minimum Spanning Tree.

Constraints
1 <= T <= 100
2 <= N <= 100
N-1 <= M <= N*(N-1)/2
1 <= u, v <= N
1 <= w <= 1000

Example
Input
2
3 3
1 2 1
2 3 2
1 3 3
4 5
1 2 4
1 3 2
1 4 3
2 3 1
2 4 5

Output
3
6
